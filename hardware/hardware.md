# 🛠️ Project Hardware Specifications

This document outlines the core hardware components utilized for this build, detailing their structural parameters, electrical ratings, and operational constraints.

## 📦 Component Overview

### 🔄 A2212 Brushless Motor
* **Configuration:** 930KV / 1000KV outrunner brushless motor equipped with pre-soldered bullet plugs.
* **Application:** Primary high-velocity propulsion/rotation unit.

### ⚡ XXD 30A Brushless ESC
* **Configuration:** 30A Electronic Speed Controller optimized for multirotor and fixed-wing brushless motors.
* **Application:** Interprets PWM signals from the microcontroller to regulate motor RPM and drive phase transitions safely.

### 🧭 GHPYQKC Hall Sensor Module
* **Configuration:** Integrated magnetic field threshold/linear detection break-out board.
* **Application:** Positional tracking, indexing, or rotational speed sensing via proximity to structural magnets.

### 💡 WS2812B Addressable LED Strip
* **Configuration:** 5V DC, Black PCB backing, high-density matrix (144 LEDs per meter), IP30 non-waterproof rating.
* **Application:** Visual telemetry, state identification, or dynamic lighting effects via a single-wire digital interface.

### 🥢 Model Shaft Tubes
* **Configuration:** Precision-diameter metallic rod/axle structure (1mm–18mm range, 1x500mm profile).
* **Application:** Structural load bearing, rotational axle connection, or linear guide rails.

### 🧲 N35 Neodymium Magnets
* **Configuration:** High-coercivity rare-earth permanent magnets (5mm x 2mm sizing specification).
* **Application:** Excitation source for the Hall sensor array or structural latching/alignment mechanisms.
